# Instruction Encoding Worksheet


## 1. R-Type: add x4, x5, x10

- opcode = 0110011
- funct3 = 000
- funct7 = 0000000
- rd  = x4  = 00100
- rs1 = x5  = 00101
- rs2 = x10 = 01010

Binary:
0000000 | 01010 | 00101 | 000 | 00100 | 0110011

Full 32-bit:
0000000_01010_00101_000_00100_0110011

Hex: 0x00A28233

---

## 2. I-Type: addi x2, x0, 5

- opcode = 0010011
- funct3 = 000
- rd  = x2 = 00010
- rs1 = x0 = 00000
- imm = 5  = 000000000101

Binary:
000000000101 | 00000 | 000 | 00010 | 0010011

Full 32-bit:
000000000101_00000_000_00010_0010011

Hex: 0x00500113

---

## 3. S-Type: sw x7, 8(x8)

- opcode = 0100011
- funct3 = 010
- rs1 = x8 = 01000  (base)
- rs2 = x7 = 00111  (source)
- imm = 8  = 0000000_01000
  imm[11:5] = 0000000
  imm[4:0]  = 01000

Binary:
0000000 | 00111 | 01000 | 010 | 01000 | 0100011

Full 32-bit:
0000000_00111_01000_010_01000_0100011

Hex: 0x00742423

---

## 4. B-Type: beq x1, x2, +16

- opcode = 1100011
- funct3 = 000
- rs1 = x1 = 00001
- rs2 = x2 = 00010
- offset = 16 = 0x10
  binary offset = 0000000_10000
  imm[12]    = 0
  imm[10:5]  = 000000
  imm[4:1]   = 1000
  imm[11]    = 0

Binary:
0_000000 | 00010 | 00001 | 000 | 1000_0 | 1100011

Full 32-bit:
0000000_00010_00001_000_10000_1100011

Hex: 0x00208863

---

## 5. U-Type: lui x5, 0x12345

- opcode = 0110111
- rd  = x5 = 00101
- imm[31:12] = 0x12345 = 00010010001101000101

Binary:
00010010001101000101 | 00101 | 0110111

Full 32-bit:
00010010001101000101_00101_0110111

Hex: 0x123452B7

---

## 6. J-Type: jal x1, +8

- opcode = 1101111
- rd  = x1 = 00001
- offset = 8
  binary = 000000001000
  imm[20]    = 0
  imm[10:1]  = 0000000100
  imm[11]    = 0
  imm[19:12] = 00000000

Scrambled immediate layout [20|10:1|11|19:12]:
0 | 0000000100 | 0 | 00000000

Binary:
0_0000000100_0_00000000 | 00001 | 1101111

Full 32-bit:
00000000100000000000_00001_1101111

Hex: 0x008000EF
